# 月次経理レポートスキル（keiri-monthly）

## 概要
毎月の経理データから以下をExcelで自動生成する：
1. 資金繰り表（キャッシュフロー）
2. 試算表（残高試算表）
3. 月次推移表（PL月次比較）

## 対象口座（医療法人 恵聖会）
| 口座 | 用途 |
|---|---|
| さくら眼科クリニック（SMBC） | メイン診療口座 |
| 医療法人 恵聖会（常陽銀行） | 法人口座 |
| ルミナス 常陽銀行 | サブ口座 |
| 医療法人 恵聖会（イケイセイカイ） | 法人口座2 |
| 楽天銀行 医療法人 | ネット口座 |
| ルミナス楽天口座 | サブネット口座 |

## 資金繰り表の構成

### 収入カテゴリ
売上高、診療報酬（社保）、診療報酬（国保）、窓口収入、自費診療、その他収入

### 支出カテゴリ（人件費）
給料賃金、法定福利費

### 支出カテゴリ（経費）
地代家賃、水道光熱費、通信費、医薬品費、備品・消耗品費、業務委託料、リース料、支払報酬、広告宣伝費、修繕費、保険料、接待交際費、旅費交通費、研修費、支払手数料、その他経費

### 差引
当月収支 = 収入合計 - 支出合計
翌月繰越残高 = 当月収支 + 前月繰越残高

## 試算表の構成
- 資産の部（現金、普通預金各口座、売掛金、未収金）
- 負債の部（未払金、預り金、借入金）
- 純資産の部（元入金）
- 収益の部（売上高、各診療報酬）
- 費用の部（全経費科目）
- 借方合計＝貸方合計の検証付き

## フォーマット要件
- タイトル: 16pt太字、中央揃え
- セクションヘッダー: 12pt太字、背景色薄青
- 合計行: 太字、上線付き
- 金額: 円記号カンマ区切り、マイナスは赤字
- 印刷範囲設定済み（A4横）
- Excel数式使用（SUM等）

## 入力データ
- MoneyForwardエクスポートCSV
- keiri-invoiceで作成した仕訳一覧Excel
- 銀行口座TSV/CSVデータ

## 注意事項
- 医療法人の会計年度は4月〜3月
- 診療報酬は2ヶ月遅れで入金
- 金額の整合性チェックを必ず行う
