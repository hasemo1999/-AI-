# 月次経理レポートスキル（keiri-monthly）

## 概要
毎月の経理データから、以下のレポートをExcelで自動生成する：
1. **資金繰り表**（キャッシュフロー）
2. **試算表**（残高試算表）
3. **月次推移表**（PL月次比較）

## 入力データ
- MoneyForwardからエクスポートしたCSV/Excel
- 仕訳一覧Excel（keiri-invoiceスキルで作成したもの）
- 銀行口座のTSV/CSVデータ

## 対象口座（医療法人 恵聖会）
| 口座 | 用途 |
|---|---|
| さくら眼科クリニック（SMBC） | メイン診療口座 |
| 医療法人 恵聖会（常陽銀行） | 法人口座 |
| ルミナス 常陽銀行 | サブ口座 |
| 医療法人 恵聖会（イケイセイカイ） | 法人口座2 |
| 楽天銀行 医療法人 | ネット口座 |
| ルミナス楽天口座 | サブネット口座 |
| その他 | その他 |

## 収入カテゴリ
売上高、診療報酬（社保）、診療報酬（国保）、窓口収入、自費診療、その他収入

## 支出カテゴリ
### 人件費
給料賃金、法定福利費

### 経費
地代家賃、水道光熱費、通信費、医薬品費、備品・消耗品費、業務委託料、リース料、支払報酬、広告宣伝費、修繕費、保険料、接待交際費、旅費交通費、研修費、支払手数料、その他経費

## 使い方
1. 「今月の資金繰り表を作って」と依頼
2. MFの仕訳データCSVを添付するか、ブラウザでMFからデータ取得
3. 自動でExcelレポートが出力される

## 注意事項
- 医療法人の会計年度は4月〜3月
- 診療報酬は2ヶ月遅れで入金
- 消費税は原則課税（簡易課税の可能性あり）
- 金額の整合性チェックを必ず行う
